# Experiment B: Cross-Session Predictive Evaluation

This directory contains the data products, predictive results, session-level evaluation results, predictions, and feature-target correlation analyses associated with **Experiment B**.

Experiment B is the primary predictive evaluation of the proof-of-concept analytics pipeline developed within the Real-Time Digital Twin Architecture for Additive Manufacturing project.

> **Important:** The predictive target used in this experiment is a synthetic session-progress proxy. It is not a physical Remaining Useful Life (RUL) measurement, degradation indicator, component-health measurement, or failure prediction target.

---

## Experiment Overview

Experiment B evaluates whether relationships learned from machine telemetry can generalize to **previously unseen operating sessions**.

Unlike observation-level evaluation procedures that may split observations from the same session, Experiment B performs evaluation at the **session level**.

The workflow is:

```text
High-Frequency Telemetry
        |
        v
Session Identification
        |
        v
1-Minute Window Aggregation
        |
        v
Feature Extraction
        |
        v
Session-Level Train/Test Separation
        |
        v
Model Training
        |
        v
Prediction on Unseen Sessions
        |
        v
Overall and Session-Level Evaluation
```

The telemetry data are aggregated into approximately one-minute windows before model development.

The file also contains:

```text

```

This variable represents the relative temporal progress of a telemetry window within its operating session.

Conceptually:

```text

```

This variable is a synthetic proxy used for proof-of-concept predictive evaluation.

It should **not** be interpreted as:

- Remaining Useful Life;
- physical degradation;
- component health;
- failure probability.

### Additional variable

The dataset also includes:

```text

```

which represents the fraction of activity identified within the corresponding time window.

# Evaluation Metrics

## Pearson Correlation Coefficient (`R`)

Measures the linear association between predicted and actual values.

## Coefficient of Determination (`R²`)

Measures how well the predictions explain the variance of the target.

Negative values indicate that predictions perform worse than a constant prediction based on the target mean.

## Mean Absolute Error (`MAE`)

Measures the average absolute difference between predicted and actual values.

## Mean Squared Error (`MSE`)

Measures the average squared prediction error.

## Root Mean Squared Error (`RMSE`)

Measures prediction error while giving greater weight to larger errors.

## Explained Variance Score (`EVS`)

Measures the proportion of variation explained by the predictions.

# Interpretation of Results

Experiment B is designed as a stricter evaluation because complete operating sessions are separated between model development and evaluation.

The results demonstrate whether predictive relationships learned from training sessions generalize to telemetry collected during previously unseen sessions.

Under this cross-session evaluation, the evaluated machine-learning models did not outperform the constant-reference baselines according to the overall evaluation results.

This finding is important because it demonstrates that:

- machine-learning models can produce predictions without providing meaningful generalization;
- successful technical integration does not automatically establish predictive capability;
- session-aware evaluation is essential;
- baseline comparison is necessary;
- physically meaningful targets are required for validated prognostic research.

The results therefore support the interpretation of the predictive component as a **proof-of-concept analytics pipeline** rather than a validated Remaining Useful Life or predictive-maintenance system.

---

# Important Limitation

The target variable used in Experiment B is:

```text
synthetic_session_progress
```

This target represents relative progress within an operating session.

It is **not equivalent to Remaining Useful Life (RUL)**.

Therefore, the results should not be interpreted as demonstrating:

- validated RUL prediction;
- component degradation modeling;
- failure prediction;
- machine-health prediction;
- predictive-maintenance effectiveness.

The primary purpose of Experiment B is to evaluate the behavior and limitations of the machine-learning pipeline when integrated into the broader Digital Twin architecture.
